# 风控模型接口的模型窃取检测与防护实验框架

面向「风控评分模型通过 API 开放给合作方」场景，检测以复制模型为目的的查询行为，
并在**不明显影响正常合作方**的前提下提高攻击者的复制代价。所有组件均为纯 Python
实现，可离线复现。

## 威胁模型

| 能力 | 说明 |
|---|---|
| 攻击者目标 | ① 蒸馏出与受害者效果接近的替代模型；② 用替代模型找绕过风控的样本 |
| 攻击方式 | 批量构造请求、收集返回分数/标签；可分散到多个账号、混入真实业务数据 |
| 攻击者已知 | 特征维度、大致取值范围、少量合法业务样本（合作方身份天然可得） |
| 正常合作方 | 调用量大、有业务波峰、查询集中在运营数据分布上，**不能被误伤** |

## 数据与受害者模型

- **公开数据集**：UCI Statlog German Credit（24 个数值特征、1000 条、二分类、
  约 30% 正样本），自动下载并缓存到 `data_store/`；网络不可用时回退到同分布合成数据。
- **受害者模型**：`HistGradientBoostingClassifier`（GBDT），测试集 AUC ≈ 0.77，
  通过 `ScoringGateway` 仅暴露 `score(x) -> {score, label}` 接口。

## 攻击实现（`attacks.py`）

1. **UniformRandom**：在特征盒内均匀盲探，覆盖整个输入空间；
2. **GaussianMimicry**：从攻击者持有的真实业务池估计均值/协方差，沿业务分布探测，
   隐蔽性最强；
3. **BoundarySearch**：主动自适应攻击——随机方向扩括号 + 二分搜索定位决策边界，
   并在边界点附近密集采样，单位预算信息量最高；
4. **LabelOnlyBoundary**：只用二分类标签的边界攻击，对分数噪声/量化天然鲁棒；
5. **DistributedAttack**：把上述攻击拆到 N 个账号、轮询分配预算，并按比例混入
   真实业务查询，稀释单账号信号。

## 检测方法

### 单账号：滑动窗口行为特征（窗口 200、步长 50、冷启动快速窗口 80）

边界命中率、特征尾部占比、相对良性流形的 KNN 新颖度、成对多样性、去重率、
标签翻转率、分数熵/极差、机器化突发节奏、移动单调性（二分搜索特征）、
坐标扰动集中度、特征空间跨度——共 12 维，按良性 99 分位锚点归一化后加权求和，
再经 EMA 平滑为 0–1 怀疑度，映射到 4 个响应等级。**原始调用量权重很低**，
避免误伤高量合作方。冷启动阶段在第 80 个查询即做首次评估，堵住小预算攻击
利用"攒满窗口才检测"的时间窗。

### 跨账号：行为门控 + 复合协同信号 + 并查集

精确哈希/粗网格 Jaccard 在高维（24 维）下实测不可靠：攻击账号分探不同区域时
互相 Jaccard 仅 0.03，而正常合作方因都在业务流形上，与攻击账号的 Jaccard
反而更高（0.08）。方案改为**复合协同分数**（先经行为门控，只有本身呈现窃取
特征的账号才入选）：机器化节奏匹配（恒定亚 100ms 间隔）0.35 + 行为画像相似
0.25 + 边际分布直方图相关 0.25 + 弱空间单元重合 0.15。并查集聚成账号簇，
簇内 ≥2 个成员轻度可疑时**联合提级**，对抗预算拆分。

## 防护方法（`defense.py`，按怀疑度分级）

| 等级 | 量化步长 | 确定性噪声 σ | 边界标签投毒 | 限流 | 触发 |
|---|---|---|---|---|---|
| L0 可信 | 无 | 0 | 无 | 无 | 正常合作方，**分数原样返回** |
| L1 观察 | 0.01 | 0.002 | 无 | 无 | 轻微异常，影响可忽略 |
| L2 可疑 | 0.05 | 0.02 | 15%（边界带内） | 5 QPS | 单账号行为证据充分 |
| L3 确认 | 0.10 | 0.05 + 向阈值牵引 | 30%（边界带内） | 1 QPS | 边界猎杀/跨账号簇 |

关键设计：

- **确定性、按 (账号, 特征向量, 轮换盐) 播种的噪声**——同一查询在盐周期内返回
  一致答案，服务语义稳定；攻击者无法靠重复查询平均掉噪声，换账号盐也不同；
- **盐定期轮换**（默认每 5 万次调用），跨周期采集的训练标签互相冲突；
- **高等级噪声向 0.5 决策阈值牵引**，优先破坏替代模型的边界几何；
- **边界定向标签投毒**：只对 L2/L3 且分数落在阈值 ±0.15 带内的查询，按确定性
  哈希以固定概率把标签翻到阈值另一侧并留出 margin。替代模型用硬标签蒸馏时，
  恰好在决策边界附近学到错误标签——这是对复制杀伤力最集中的机制，而正常合作方
  （L0/L1）和远离边界的查询完全不受影响；
- 分数量化让攻击者拿到的标签分辨率随怀疑度下降，标签-only 攻击同样受影响。

## 评估指标（`artifacts/reports/`）

- 检测：窗口级 precision / recall / F1 / FPR / ROC-AUC，RF 特征重要性；
- 复制代价：替代模型与受害者的标签一致率、分数 RMSE、Spearman、AUC 差距，
  随窃取预算（200→8000）的曲线，对照 undefended / defended 两种 API；
- 绕过效果：替代模型引导生成的对抗样本对**受害者**的实际绕过率与 L2 扰动；
- 正常合作方影响：分数 MAE、标签翻转率、限流率、达到的最高等级。

## 实测结论（German Credit，全量实验）

**检测（窗口级）**：规则检测器 precision=1.00 / recall=0.98 / FPR=0.00 / ROC-AUC=1.00；
随机森林检测器四项全为 1.00。最重要的特征是机器化突发节奏（重要性 0.29）、
新颖度（0.20）、特征尾部占比（0.16）、坐标扰动集中度（0.14）——没有一个依赖原始调用量。

**正常合作方零误伤**：9000 条业务查询，分数 MAE=3e-05、**标签翻转 0、限流 0**，
最高仅触及 L1（轻微噪声，σ=0.002）。

**攻击者代价**：66800 条攻击查询中 98.9% 被升到 L2+、71.4% 到 L3、88.4% 被限流，
返回分数相对真实值平均偏差 0.071。

**复制保真度**：所有预算下替代模型与受害者的标签一致率被稳定拉低 3–6 个百分点
（如 8000 预算的均匀攻击 0.960→0.876），且该差距**不随预算收敛**；边界攻击的替代
模型 AUC 在中低预算下降最多（1000 预算 0.738→0.676）。

**消融（预算 2000 的平均）**：

| 变体 | 标签一致率 | 替代模型 AUC | 良性 MAE | 良性翻转 |
|---|---|---|---|---|
| 无防护（仅检测） | 0.918 | 0.759 | 0 | 0 |
| 仅噪声 | 0.873 | 0.727 | 0 | 0 |
| 仅量化 | 0.914 | 0.760 | 1e-4 | 0 |
| 噪声+量化 | 0.873 | 0.751 | 1e-4 | 0 |
| 完整（+标签投毒） | 0.867 | 0.753 | 1e-4 | 0 |

确定性噪声是主力（硬标签蒸馏主要被边界附近的标签翻转破坏），量化单独几乎无效但
与噪声有协同，标签投毒在噪声之上进一步压低一致率。

## 局限与诚实说明

- 这是离线仿真：时间戳、账号行为、攻击策略都是建模的，真实部署需用线上审计流
  重新校准锚点，并配合账号注册/支付等反滥用信号；
- 防护**提高而非消除**复制成本：高预算、严格模仿业务分布的 GaussianMimicry 最难
  检测，替代模型在大预算下 AUC 仍可接近受害者——这是模型窃取防御的固有上界；
- 评估里替代模型用硬标签蒸馏；若攻击者改用软标签回归，量化的杀伤力会变化，
  可在 `evaluation.train_surrogate` 中切换蒸馏目标进一步实验。
